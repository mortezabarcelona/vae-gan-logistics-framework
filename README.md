# VAE-GAN Logistics Framework

This project implements a hybrid VAE-GAN model for intelligent logistics scenario generation, dynamic routing, and freight exchange optimization.

## Features

- Variational Autoencoders (VAE)
- Generative Adversarial Networks (GAN)
- Hybrid VAE-GAN integration
- Dynamic routing engine
- Synthetic logistics data generator
- Multi-agent freight exchange module
